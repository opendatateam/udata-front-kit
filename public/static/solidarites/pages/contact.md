# Nous contacter

## À propos du site solidarites.data.gouv.fr

Pour toute question, suggestion ou difficulté concernant les contenus éditoriaux, les ressources mises en avant ou le fonctionnement propre à solidarites.data.gouv.fr, vous pouvez contacter l’AMDAC MSS : amd@sante.gouv.fr.

## À propos de la qualité d’un jeu de données

Si vous constatez une erreur, une omission ou une difficulté relative à un jeu de données présenté sur solidarites.data.gouv.fr, vous pouvez la signaler à l’AMDAC MSS : [amd@sante.gouv.fr](mailto:amd@sante.gouv.fr).

Le signalement pourra être transmis à l’organisme producteur concerné afin qu’il puisse l’examiner et, le cas échéant, mettre à jour le jeu de données publié sur data.gouv.fr.

Afin de faciliter le traitement du signalement, précisez si possible le titre du jeu de données, le lien vers sa fiche data.gouv.fr, la ressource concernée et la nature du problème constaté.

## Pour demander un de jeu de données

Le portail solidarites.data.gouv.fr présente l’ensemble des jeux de données ouverts par les membres du RPDS et disponibles dans data.gouv.fr.

Dans le cas où vous identifiez le besoin de recourir à des données qui ne seraient pas présente dans l’offre du portail, vous pouvez contacter l’AMDAC MSS : [amd@sante.gouv.fr](mailto:amd@sante.gouv.fr).

La demande pourra être transmise à l’organisme producteur concerné afin qu’il puisse l’examiner, et, le cas échant, publier le jeu de données sur data.gouv.fr.

## À propos des fonctionnalités de data.gouv.fr

Pour toute question relative aux fonctionnalités data.gouv.fr (telles que la gestion d’un compte, l’inscription, la connexion, la publication…), utilisez le support de data.gouv.fr.

[Accéder au support de data.gouv.fr](https://support.data.gouv.fr/)

## Demandes individuelles

Le contact du site thématique n’a pas vocation à recevoir ni à traiter des demandes relatives à la situation individuelle d’un usager dans ses relations avec une administration. Pour ces démarches, utilisez le téléservice ou le point de contact de l’administration compétente.
